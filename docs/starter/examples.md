# Express examples

This page contains list of examples using Express.

- [auth](https://github.com/abedmurrar/express/tree/master/examples/auth) - Authentication with login and password
- [content-negotiation](https://github.com/abedmurrar/express/tree/master/examples/content-negotiation) - HTTP content negotiation
- [cookie-sessions](https://github.com/abedmurrar/express/tree/master/examples/cookie-sessions) - Working with cookie-based sessions
- [cookies](https://github.com/abedmurrar/express/tree/master/examples/cookies) - Working with cookies
- [cookies-behind-proxy](https://github.com/abedmurrar/express/tree/master/examples/cookies-behind-proxy) - Secure and `SameSite` cookies behind an HTTPS proxy
- [downloads](https://github.com/abedmurrar/express/tree/master/examples/downloads) - Transferring files to client
- [ejs](https://github.com/abedmurrar/express/tree/master/examples/ejs) - Working with Embedded JavaScript templating (ejs)
- [error-pages](https://github.com/abedmurrar/express/tree/master/examples/error-pages) - Creating error pages
- [error](https://github.com/abedmurrar/express/tree/master/examples/error) - Working with error middleware
- [graceful-shutdown](https://github.com/abedmurrar/express/tree/master/examples/graceful-shutdown) - Stopping without cutting off responses
- [hello-world](https://github.com/abedmurrar/express/tree/master/examples/hello-world) - Simple request handler
- [markdown](https://github.com/abedmurrar/express/tree/master/examples/markdown) - Markdown as template engine
- [multi-router](https://github.com/abedmurrar/express/tree/master/examples/multi-router) - Working with multiple Express routers
- [mvc](https://github.com/abedmurrar/express/tree/master/examples/mvc) - MVC-style controllers
- [online](https://github.com/abedmurrar/express/tree/master/examples/online) - Tracking online user activity with `online` and `redis` packages
- [params](https://github.com/abedmurrar/express/tree/master/examples/params) - Working with route parameters
- [resource](https://github.com/abedmurrar/express/tree/master/examples/resource) - Multiple HTTP operations on the same resource
- [route-map](https://github.com/abedmurrar/express/tree/master/examples/route-map) - Organizing routes using a map
- [route-middleware](https://github.com/abedmurrar/express/tree/master/examples/route-middleware) - Working with route middleware
- [route-separation](https://github.com/abedmurrar/express/tree/master/examples/route-separation) - Organizing routes per each resource
- [search](https://github.com/abedmurrar/express/tree/master/examples/search) - Search API
- [session](https://github.com/abedmurrar/express/tree/master/examples/session) - User sessions
- [static-files](https://github.com/abedmurrar/express/tree/master/examples/static-files) - Serving static files
- [testing-without-a-port](https://github.com/abedmurrar/express/tree/master/examples/testing-without-a-port) - Testing with `light-my-request`
- [vhost](https://github.com/abedmurrar/express/tree/master/examples/vhost) - Working with virtual hosts
- [view-constructor](https://github.com/abedmurrar/express/tree/master/examples/view-constructor) - Rendering views dynamically
- [view-locals](https://github.com/abedmurrar/express/tree/master/examples/view-locals) - Saving data in request object between middleware calls
- [web-service](https://github.com/abedmurrar/express/tree/master/examples/web-service) - Simple API service
